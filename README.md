# GCP floci, redis, litellm and llama server based flask code generator app from meeting notes

This code is simulation of standard pub sub architecture where producer produces message and consumer acts on the message

## Producer: 
Produces meeting notes at constant rate by querying llm hosted through llama server outside of the docker in local host

## Consumer: 
Summarizes meeting notes generated by producer and post summarization generate flask code with docker compose file. Consumer also pushes this code into gcp bucket created by floci so that user can download the generated code

## Dashboard: 
Real time dashboard to monitor the process and download the code on completion

#  Llama server setup
Llama server setup command  [https://github.com/ggml-org/llama.cpp/tree/master/tools/server]

# Code command

```
cd FlaskCodeGeneratorApp
docker compose up --build
```

# Note
Ensure llama servers are spinned up and port numbers are assigned in the consumer.py and producer.py file before running compose command

# How to run Flask code generated by this app
  ```Download code
     cd codefolder
     docker compose up --build
 ```
